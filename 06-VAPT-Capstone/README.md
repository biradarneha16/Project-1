# Comprehensive Penetration Testing Report & Capstone

Enterprise-style VAPT capstone for the Project-1 authorized security lab.

## Scope
This report consolidates the authorized security-lab assessments performed in Project-1, including network reconnaissance, web-application testing, authentication/cryptography review, evidence collection, risk classification, remediation, and retesting.

## Deliverables
- `VAPT-Capstone-Report.md` — executive-ready report source.
- `risk-register.csv` — structured finding register.
- `remediation-checklist.md` — developer and sysadmin remediation checklist.

## Important
CVSS 3.1 scores must be calculated from the actual confirmed evidence and applicable CVSS vector. Placeholder scores are deliberately not invented. Production testing requires explicit authorization and scope.

## Expected proof
Formal VAPT report, risk register, remediation evidence, screenshots/tool output, and mentor review record.
