# Cryptography, Key Management & Secure Authentication

Educational security module covering AES-256-GCM authenticated encryption, RSA-2048 digital signatures, HMAC-SHA-256 integrity checks, bcrypt password hashing, and secure key-management practices.

No private keys, passwords, tokens, or generated secrets are stored in this repository.

See crypto_utils.py for the demonstration and key_management.md for secure storage and rotation guidance.
